# FrameFlow

FrameFlow 是一个通用的 AI 视频创作工作台。你可以从一个创意开始，编辑故事和脚本，管理分镜、角色、首尾帧、配音和音乐，选择对应的 AI 接口后提交视频生成任务。生成过程在后台异步执行，可以在任务中心查看进度、取消任务、失败重试和下载结果。

## 开发指南

开始开发前请阅读 [项目开发守则](AGENTS.md)、[DDD 与工程指南](docs/development-guide.md) 和 [架构治理决策](specs/architecture-governance/design.md)。这些文件区分现有实现与目标架构；模型接入体系的后续改造将按此基线进行。

## 一键安装

在 Windows PowerShell 中执行下面一条命令。脚本会从 GitHub Releases 下载最新版本并立即启动：

```powershell
irm https://raw.githubusercontent.com/fengxiaozi-liu/FrameFlow/main/scripts/install-windows.ps1 | iex
```

程序安装到当前用户的 `%LOCALAPPDATA%\FrameFlow`，启动后访问 `http://127.0.0.1:28741`。运行数据保存在安装目录下的 `data` 文件夹。

## 使用方式

场景/人物多图、描述、音色及逐句台词工作台的使用与升级说明见 [绑定功能迁移说明](docs/migrations/scene-character-binding.md)。

应用首页点击「查看入门指南」，或从侧栏「操作指南」打开当前页面对应的步骤。指南包含编号截图、放大预览、完成检查和常见问题。

1. **配置模型**：在「模型管理」添加厂商连接，填写 HTTPS 基础域名及认证信息。百炼使用内置模型同步接口；自定义厂商在添加连接或「连接设置」中填写同步路径、JSON 示例及列表 / ID / 名称 Key。同步只负责导入模型，生成能力在各模型的「协议与参数」中设置并启用。
2. **准备故事**：进入「创作工作台」新建或继续项目，直接输入、粘贴或导入正文。也可使用「故事联想」，生成后先预览，再选择追加或替换正文；AI 联想可以跳过。
3. **创建分镜**：正文保存后生成候选分镜，检查并点击「应用分镜」；也可手动新增镜头，整理顺序后进入详情。
4. **配置人物与场景**：添加或复用设定，选择素材库图片、本地上传，或使用「图片生成」。图生图须先在模型配置中启用并填写图片限制，再按顺序添加 PNG / JPEG 参考图、写明修改要求。结果需主动使用并保存引用；希望跨项目复用时另点「上传到素材库」，原图保留。
5. **生成并选用视频**：选择模型、首尾帧或智能参考模式、比例、时长及清晰度。在当前分镜下方查看「生成记录」，完成后进入任务预览，点击「选用此结果」。每次提交为独立任务；若远端受理状态未知，先在服务商确认，不能直接重试。
6. **合成与下载**：每个镜头选用一个视频版本后，进入「成片」或「视频」页，设置音乐、画幅和清晰度，点击「导出完整成片」。完成后在「成片历史」预览并下载；更换片段后需要重新导出。

模型接入与扩展见 [模型协议配置指南](docs/model-protocols.md)。
