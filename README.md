# FrameFlow

FrameFlow 是一个通用的 AI 视频创作工作台。你可以从一个创意开始，编辑故事和脚本，管理分镜、角色、首尾帧、配音和音乐，选择对应的 AI 接口后提交视频生成任务。生成过程在后台异步执行，可以在任务中心查看进度、取消任务、失败重试和下载结果。

## 一键安装

在 Windows PowerShell 中执行下面一条命令。脚本会从 GitHub Releases 下载最新版本并立即启动：

```powershell
irm https://raw.githubusercontent.com/fengxiaozi-liu/FrameFlow/main/scripts/install-windows.ps1 | iex
```

程序安装到当前用户的 `%LOCALAPPDATA%\FrameFlow`，启动后访问 `http://127.0.0.1:28741`。运行数据保存在安装目录下的 `data` 文件夹。

## 使用方式

1. 在首页输入视频创意，点击开始创作。
2. 在工作台编辑故事正文和分镜，分别选择故事、生图和视频 AI 接口。提交生成时，任务会自动关联当前项目和草稿。
3. 在独立的“素材管理”页面分类上传、预览、选择或删除画面、角色、首尾帧、配音和音乐。
4. 点击生成按钮后离开页面也不会中断任务；故事生成完成后会自动回填所属草稿的策划正文。
5. 在任务中心按项目和草稿查看进度；任务完成后下载结果，失败时可以重试。升级前创建、无法判断归属的任务会显示在“未归属任务”中。
6. 在配置中心新增厂商连接、填写模型和 API Key，并测试连接。角色和首尾帧共用生图接口。
