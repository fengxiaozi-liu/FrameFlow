# 完整首页入门指南

首页保留介绍与轮播，入门区升级为四步：配置模型、故事联想（可跳过）、生成分镜、合成视频。每步包含准备内容、实际操作、界面示意、完成检查及常见问题。分镜步骤明确正文候选需要应用、场景/人物引用与参考图；合成步骤明确先生成并选用每个镜头的视频版本，再设置与导出成片。

采用数据驱动指南内容与代码绘制的操作示意，示意显式标注、与真实字段和按钮对应。桌面指南为可滚动正文与示意侧栏，移动端纵向排列；步骤导航和翻页可随时使用。跳转按钮分别进入模型管理、新建正文、工作台选择已有项目。已有正文跳过联想，示例想法仅在用户点击后传入；阅读与翻页不写项目、不调用生成。

保留首页轮播、可访问性、关闭焦点恢复与新建路由。验证所有步骤、跳转、已有正文/示例两种路径、问题展开、桌面/手机滚动与键盘、现有业务回归及独立 EXE 启停。生成调用采用隔离测试，不使用付费服务。
