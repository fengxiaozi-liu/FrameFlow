# 工作台交互契约 v1

主题：工作台暗色底 #101817、卡片 #182421、正文 #E6F4F1、次级文字 #A2BAB3、边界 #45645C；主色 #14B8A6、hover #2DD4BF、pressed #0D9488。暗色主按钮使用 #062D29 字色；亮底主按钮使用 #0F766E 与白字。焦点使用 2px #2DD4BF 实线并留 2px 间隙；错误用文字和图标提示，不只改变颜色。

布局：上方小视频预览与台词区，下方宽编辑面板。卡片默认展开，左描述右多图；缩略图 72–88px，超过宽度横向滚动；900px 以下面板顺序堆叠，描述和参考图上下排列。不提供未实现的连线端口或自由节点拖拽。

每组明确显示名称、类型、固定档案版本、项目基础描述、本镜头补充、实际选用图片数；组内图片带视角说明、移除与排序按钮。添加图片保留已有选择，移除仅解绑。项目档案修改在独立编辑器进行，产生新版本；已有镜头明确选择升级，默认不会跟随改变。

@ 编辑使用 text/entity_ref 节点，候选中展示类型和身份信息。同名可区分；改名只更改显示值。可输入中文、退格删除整节点、复制为可读文本并重新选择身份。IM​​E 组合输入期间不能触发提交或候选确认。选中未绑定档案时保存绑定与引用必须原子完成。

音色在人物卡选择默认值，台词标记“继承人物音色”或“本句覆盖”，可恢复继承。切换试听停止前一段，离开页面停止播放。旁白不需要假造出场人物。

保存状态：未保存→保存中→已保存；失败保留输入并可重试；409 展示本地与服务端版本。生成前等待当前保存成功，重复点击不重复提交。未配置音色只阻止需要语音的步骤，不阻止无声生图。

能力提示：每模型展示每次提交的参考图上限、时长与分辨率；选用超限就地提示，不自动丢弃。档案可保存更多图片，通过镜头选用子集满足模型限制。输入预览分别列出生图和视频实际消费的描述及图片。
