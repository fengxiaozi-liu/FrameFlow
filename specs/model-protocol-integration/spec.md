# 统一模型协议接入

状态：已完成。依据：AGENTS.md、docs/development-guide.md、architecture-governance/design.md。

- RQ-001 模型 ID 为不透明标识；文本、图片、视频、语音按显式操作协议与规格执行，同协议新增模型不改代码。
- RQ-002 模型管理可编辑协议及参数规格，区分启用、配置状态、真实验证；缺失参数明确提示，前后端共用解析结果。
- RQ-003 视频支持多图参考或单图首帧，分镜引用可直接作为首帧；严格检查数量、比例、时长与分辨率，不静默丢图。
- RQ-004 旧已知模型迁移为预设配置，未知保留待配置。任务冻结模型配置及协议，修改配置不改变已提交任务。
- RQ-005 新增用例遵守 DDD 分层；协议注册隔离厂商与模型名；执行编排移至应用层。保留已有取消、幂等和恢复约束。

范围：现有 OpenAI chat-completions 格式、DashScope multimodal image/speech、DashScope media video 异步协议；其他协议明确不可用，不能因为勾选能力就声称任意接口兼容。无真实付费调用。
