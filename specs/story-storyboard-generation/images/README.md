# 创作工作台概念图

这五张图用于讨论布局、视觉风格和信息层次。工作台已按正文、故事联想、分镜、素材库和视频页的核心流程实现；功能、导航、字段和状态以 [需求规格](../spec.md) 与 [交互设计](../interaction-design.md) 为准；图中文字、数量和状态仅是示例。

| 编号 | 概念图 | 对应内容 |
| --- | --- | --- |
| 01 | [正文编辑](01-story-editor.png) | 直接输入或导入正文，故事联想为可选入口 |
| 02 | [故事联想](02-story-assistant.png) | 右侧抽屉、生成预览与显式应用 |
| 03 | [分镜与素材绑定](03-scene-assets.png) | 镜头列表、设置及单镜头素材用途 |
| 04 | [素材管理](04-material-library.png) | 五类素材、检索、详情及使用位置 |
| 05 | [视频与成片](05-video-assembly.png) | 片段版本、顺序、配乐和成片下载 |

[图片提示词归档](prompts-original.md) 中第 1～3 段是原始提示词，第 4～5 段根据现存图片和交互设计补写，不能当作生成时的逐字记录。

图 01～03 的导航和装饰细节存在生成差异；图 02 的正文插图、富文本工具及图 03 的“合成预览”均不构成首版功能承诺。具体取舍见交互设计第 1、2、12 节。

2026-09-23 对照检查：图 01 的纯文本编辑、保存状态及生成入口；图 02 的故事联想抽屉和候选显式应用；图 03 的镜头列表、编辑与素材用途；图 04 的五类素材、检索和引用位置；图 05 的片段顺序、成片设置、历史播放与下载，均已有对应界面。示例人物图片、波形装饰及富文本工具属于概念图表现，不作为运行时内容。
