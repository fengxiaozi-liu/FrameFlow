# 特性规格说明：故事、分镜与素材创作工作台

**Feature Branch**: `story-storyboard-generation`（feature 标识，不代表已切换分支）  
**Created**: 2026-09-23  
**Status**: Ready  
**Input**: 用户确认按概念图细化界面设计；支持直接输入正文和可选故事联想抽屉；正文生成分镜、分镜绑定图片与音频并生成视频；更新素材管理分类；图片保存到对应 specs 目录。

---

## 需求描述

### 背景与动机

把创作流程组织为正文、分镜、视频三个阶段，让已有完整故事的用户直接开始，让只有简短想法的用户借助故事联想补全正文。素材集中管理，在具体分镜中明确用途，避免全局选用素材影响其他镜头。

本规格配套 [详细交互设计](interaction-design.md) 和 [图片索引](images/README.md)。这是产品设计基线，Ready 表示需求可进入质量检查，不表示功能已经实现。旧 plan.md 的 RQ-001～RQ-008 属于早期结构化生成计划，本规格从 RQ-101 开始编号以避免混淆；旧计划的差异见交互设计第 11 节。

### 目标用户

- 已有正文，希望拆分镜并制作视频的创作者。
- 只有简短想法，需要辅助写作的创作者。
- 希望复用角色、场景、道具、配音和音乐的创作者。

### 核心需求

- **RQ-101**：工作台提供“正文 / 分镜 / 视频”页签，切换时保留当前编辑和选中镜头，并显示保存状态。
- **RQ-102**：用户可直接输入、粘贴或导入 UTF-8 纯文本作为正文，无需先执行故事联想；纯空白正文不能触发生成分镜。
- **RQ-103**：“故事联想”以右侧抽屉呈现，支持新建故事与基于当前正文修改；关闭抽屉保留输入、已生成预览和任务状态。
- **RQ-104**：故事生成结果先作为预览保存，只有用户明确应用才写入正文；支持追加、替换和撤销本次应用，生成期间发生的正文修改不得被静默覆盖。
- **RQ-105**：“生成分镜”基于提交时的正文生成可编辑镜头列表，不改写正文；已有分镜时先预览候选列表，确认替换后旧镜头及其素材、视频关联可恢复。
- **RQ-106**：分镜支持新增、编辑、复制、删除和排序，包含标题、画面描述、旁白、时长；排序不改变镜头身份及素材归属，复制镜头不复制任务和生成结果。
- **RQ-107**：选中分镜在右侧显示镜头设置，支持从素材库选择或上传图片、音频；确认绑定只作用于当前项目、草稿、镜头，取消选择不改变已有绑定。
- **RQ-108**：图片绑定区分角色参考、场景参考、道具参考、首帧、尾帧；同一素材可在不同镜头以不同用途使用，首帧和尾帧各至多一张，其他数量遵循所选模型限制。
- **RQ-109**：音频绑定区分生成参考、配音、背景音乐；界面明确哪些参与模型生成、哪些用于后期合成，不支持的用途不能提交为生成输入。
- **RQ-110**：单镜头及批量视频生成必须校验模型能力、必需输入、时长、画幅和素材可用性；不支持的已绑定输入不得静默忽略，错误定位到具体镜头和字段。
- **RQ-111**：任务关联提交时的镜头与输入版本，离开页面仍可执行；失败可重试；每个镜头保留历史成功版本并允许选择一个用于成片。
- **RQ-112**：修改正文、分镜描述或绑定素材后，保留已有视频并标记与当前输入不一致；后台结果不得覆盖新编辑或自动替换用户已选择的版本。
- **RQ-113**：视频页按分镜顺序预览已选片段，支持简单拼接、背景音乐、音量调整与成片下载；缺少有效片段时说明缺少哪些镜头，禁止把不完整结果作为完整成片导出。
- **RQ-114**：素材管理分类为“场景 / 角色 / 道具 / 配音 / 音乐”，提供“全部”视图；移除独立“首尾帧”分类，首尾帧仅作为图片绑定用途。
- **RQ-115**：素材管理支持上传、预览、重命名、修改分类与标签、按名称及标签搜索、按媒体类型筛选和按添加时间排序；图片显示尺寸，音频显示时长并可试听。
- **RQ-116**：素材详情展示使用位置；已绑定、被执行中任务或保留版本引用的素材不可直接永久删除；解除当前绑定不会删除文件，替换文件以新增素材处理。
- **RQ-117**：旧“画面”素材展示为“场景”；旧“首尾帧”图片保留原文件和身份，暂归“场景”并标记“原首尾帧”，允许用户重新分类；已有镜头用途和历史任务输入保持原意。
- **RQ-118**：保存失败、加载失败、上传失败、生成失败、素材缺失和模型不可用均有可读提示与重试入口；未保存成功不得提交依赖该编辑内容的新生成任务。
- **RQ-119**：桌面使用不遮挡正文的侧面板，窄屏使用单面板；所有操作支持键盘，抽屉关闭恢复触发按钮焦点，状态不只依靠颜色表达。
- **RQ-120**：五张概念图和提示词归档到本 feature；概念图与文字有差异时以交互设计的统一规则为准。

### 关键实体（若涉及数据）

- **项目 / 草稿**：创作内容及其版本边界，包含正文、分镜、结果与保存状态。
- **正文候选**：由故事联想生成、尚未应用的内容，关联原始要求和生成依据。
- **分镜**：具有稳定身份和显示顺序的镜头，包含描述、旁白、时长、素材绑定和所选视频版本。
- **素材**：可复用的图片或音频，具有名称、分类、标签、媒体信息与使用位置。
- **素材绑定**：连接具体镜头与素材，记录用途；用途不等同于素材分类。
- **生成任务 / 视频版本**：任务记录所属镜头及提交时输入，成功结果构成可选择的视频版本。
- **成片**：由明确的一组片段版本、顺序及音频设置生成的可下载结果。

### 约束与边界

- 本轮交付规格、交互设计和概念图；实际代码、接口和数据迁移在同步后的实施计划中推进。
- “道具”是本轮采用的分类设计默认值；不新增独立素材权限、团队协作、素材商城。
- 模型能力以实际配置与验证为准；不假定所有视频模型支持多图、音频参考、尾帧或任意时长；未知能力按未支持处理并说明原因。
- 素材数量、文件大小、时长和画幅限制由可用能力给出明确值，在上传或提交前展示；不能照搬早期计划的时长上限为视频模型限制。
- 分镜列表已有内容时不自动合并或猜测镜头身份；候选整批替换经明确操作执行，旧版本作为恢复点保留。
- 简单成片合成属于目标体验；专业多轨剪辑、逐字字幕、转场市场和自动配音生成不在本轮设计范围。
- 同项目不同草稿、不同项目以及已删除镜头的任务结果不得串写；已删除镜头结果仍可在任务中心查看。
- 历史数据兼容是上线条件，不能通过删除旧素材或清空草稿完成分类调整。
