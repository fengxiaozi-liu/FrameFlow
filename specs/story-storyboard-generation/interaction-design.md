# FrameFlow 创作工作台详细交互设计

日期：2026-09-23 · 状态：设计基线，尚未实现  
关联：[需求规格](spec.md) · [概念图及提示词](images/README.md)

## 1. 核心流程与信息架构

主流程：直接输入正文（或故事联想 → 预览 → 应用正文）→ 生成分镜 → 绑定图片/音频 → 生成镜头视频 → 选择版本 → 合成下载。

全局顶部导航统一为“创作工作台 / 素材管理 / 任务中心 / 配置中心”。项目内部页签统一为“正文 / 分镜 / 视频”，固定在项目标题下方左侧。全局导航与项目内导航不混用。项目标题、草稿名称、保存状态在三个页签保持同一位置。

| 页面 | 主内容 | 右侧区域 | 主要操作 |
| --- | --- | --- | --- |
| 正文 | 纯文本编辑器 | 按需打开故事联想 | 生成分镜 |
| 分镜 | 镜头列表与状态 | 当前镜头设置 | 生成本镜头视频 |
| 视频 | 播放预览与片段顺序 | 成片设置 | 合成视频 |
| 素材管理 | 素材分类与卡片 | 按需打开素材详情 | 上传素材 |

同一页只展开一个主要侧面板；素材选择在镜头面板内部切换视图，顶部“返回镜头设置”，不叠加第二个抽屉。桌面使用推开内容的面板，不用暗色遮罩遮住工作内容。

## 2. 视觉、布局与响应式

| 项目 | 设计值 |
| --- | --- |
| 背景 / 面板 | #F7F8FA / #FFFFFF |
| 主要文字 / 次要文字 | #182330 / #64748B |
| 主色 / 选中浅底 | #087F78 / #EAF6F4 |
| 边线 / 圆角 | #E2E8F0、1px / 卡片 12px、输入 8px |
| 间距 | 基础 8px；控件间 12–16px；分区间 24px；页面边距 32px |
| 字号 | 项目标题 28px；分区标题 18px；正文编辑 16px、行高 1.8；控件 14px；辅助 12px |
| 控件高度 | 常规按钮与输入 40px；主要提交按钮 44px |
| 桌面框架 | 顶栏 64px；内容最大宽度 1600px；抽屉 400–460px；分镜区剩余空间自适应 |

≥1280px：列表/编辑器与侧面板并排；正文无抽屉时阅读区最大宽度约 900px。768–1279px：面板打开后优先保证可读宽度，放不下两列时切换单面板。<768px：全宽详情页式面板，显示返回按钮；素材网格按可用宽度变为两列或一列，工具栏换行。视频预览按画幅缩放，不产生整页横向滚动。

按钮区分主操作、次操作、危险操作；每个面板最多一个实心主按钮。状态使用文字加图标，选中项有边框及语义标记。键盘可操作分类、列表、更多菜单、抽屉和排序；提供“上移 / 下移”替代拖拽。动效约 180ms，尊重减少动态效果偏好。正文可读、焦点可见与内容完整优先于还原图片像素。

## 3. 正文编辑页（RQ-101～RQ-105）

参考图：[01 正文编辑](images/01-story-editor.png)。

### 3.1 默认内容

项目栏显示项目名、草稿名、“保存中 / 已保存 / 保存失败”。编辑器工具栏提供“导入文本”和“故事联想”；右侧主操作为“生成分镜”。首版使用纯文本正文，不依赖图片内出现的富文本工具。

空态文案：“写下或粘贴你的故事，也可以从一个想法开始。”编辑器始终可以输入；故事联想是可选入口。底部显示字数与保存状态，空白字符不使“生成分镜”可用。

导入支持 UTF-8 `.txt`，不解析 Word/PDF。已有正文时先展示文件内容预览，提供“追加到末尾 / 替换正文 / 取消”；解码或读取失败时保留原文。替换形成可撤销操作。

### 3.2 保存和切换

停止编辑约 800ms 后发起自动保存；切页、切镜头和提交生成前确保相关内容保存成功。保存失败保留当前输入并提供重试，显示“尚未保存，暂不能生成”。刷新或关闭页面时有未保存内容则触发离开提醒，不伪装为已保存。

正文已有分镜时继续编辑，页签上显示“分镜可能需要更新”；不自动删除分镜或其视频。重复点击生成按钮在提交处理中不重复创建任务。

## 4. 故事联想抽屉（RQ-103、RQ-104）

参考图：[02 故事联想](images/02-story-assistant.png)。

从上到下为标题及关闭、模式、想法/修改要求、可选风格、生成按钮、结果预览、应用操作。模式为“新建故事 / 修改正文”；正文为空时修改模式不可用并说明原因。风格默认不选，提供“温暖治愈 / 电影感 / 日常”快捷选项；模型选择放在折叠的“生成设置”中，展示当前模型摘要。

| 状态 | 抽屉行为 | 正文行为 |
| --- | --- | --- |
| 未生成 | 保留输入，输入为空时禁止提交 | 可编辑 |
| 排队/生成中 | 状态文字、查看任务入口，同一抽屉的生成按钮暂不可重复提交 | 可继续编辑 |
| 已生成 | 可编辑预览、重新生成、应用到正文 | 尚未改变 |
| 应用时正文已变化 | 提示“正文已有修改，请核对后应用”，再次展示追加/替换范围 | 保留最新正文 |
| 失败 | 显示原因，原输入与上一份成功预览保留，提供重试 | 不变 |
| 关闭后重开 | 恢复同草稿输入、预览和任务状态 | 不变 |

新建模式使用想法；修改模式使用提交时正文和修改要求。生成结束始终先进入预览，不能因为没有检测到冲突就自动写入正文。用户应用时可追加或替换，替换前展示字数及影响说明；已有分镜仅标记需复核。应用完成提示“已应用，可撤销”，撤销恢复应用前正文；之后再发生编辑时需预览恢复内容，不能一键丢失后续修改。

关闭抽屉不取消后台任务；跨项目结果只保留到原所属草稿。正文候选与任务可在重新打开项目后恢复，不能只依赖临时通知。首版不做逐段自动合并。

## 5. 从正文生成和维护分镜（RQ-105、RQ-106）

参考图：[03 分镜与素材](images/03-scene-assets.png)。

点击“生成分镜”打开轻量设置：期望镜头数“自动 / 指定”、可选目标总时长、当前故事模型。默认自动数量且不指定总时长；目标时长用于规划，不代表模型能生成任意长度视频。完成后显示候选镜头数量和总时长，再由“应用分镜”确认；正文不改写。

已有分镜时明确提示“替换 N 个镜头；当前分镜版本会保留，可恢复”。应用候选前保存完整旧版本，包含镜头身份、顺序、绑定和已选视频。替换后的新镜头不能按序号自动继承旧素材/结果。用户编辑了正文或现有镜头时，候选标记“基于较早内容生成”，重新确认后才能应用。

### 5.1 列表结构

顶部显示镜头数量、预计时长、“新增分镜”和“批量生成视频”。每行包含拖动柄、勾选、序号、16:9 缩略图、标题、两行画面描述、时长、素材数量、任务状态及更多操作。无图片时展示中性占位，不将参考图误称为生成的视频。

选中行以浅青色底和描边显示，右侧对应同一镜头。更多操作包括复制、上移、下移、删除。复制保留描述及素材绑定，创建独立镜头，不复制任务、视频版本或已选结果。删除提示引用与执行中任务，保留可恢复的分镜版本；完成的旧任务结果只留在任务中心，不重新插入已删除镜头。

### 5.2 镜头设置顺序

镜头标题 → 画面描述 → 旁白文本（可选）→ 时长及画幅 → 参考图片 → 音频 → 折叠生成设置 → 固定底部“生成本镜头视频”。画面描述是生成输入；旁白文本不会自动变成音频，首版不暗示具备语音合成。

描述示例：“清晨的阳光穿过薄纱，镜头缓缓推向窗边木桌。”未选模型可编辑内容，生成按钮指向明确的模型选择错误。界面提示时长范围取自当前模型，不沿用旧计划的 1–600 秒作为通用视频范围。

## 6. 分镜素材绑定（RQ-107～RQ-110）

### 6.1 图片

每张绑定卡片展示预览、名称、用途、更换和移除。用途为“角色参考 / 场景参考 / 道具参考 / 首帧 / 尾帧”。素材库分类只辅助默认用途：场景、角色、道具分别默认对应参考用途，用户仍可选择模型允许的其他用途。

“添加图片”在当前面板进入素材选择视图，提供“从素材库选择 / 上传图片”。选择视图显示当前镜头、用途、已选数量、可选上限、搜索与分类。点击确认才改变绑定；返回或取消保留原绑定。首帧、尾帧各单选，已有图片时操作文案为“替换首帧/尾帧”；参考多图上限由模型决定。

更换模型后重新校验全部绑定。若模型只支持单张首帧，额外参考仍保留在草稿，但显示不兼容并阻止提交，提供调整用途、移除或更换模型入口；不能悄悄丢弃参考图继续生成。

### 6.2 音频

| 用途 | 是否进入视频模型 | 首版交互 |
| --- | --- | --- |
| 生成参考 | 仅在所选模型支持时 | 试听、替换、移除；显示模型接受限制 |
| 镜头配音 | 默认用于镜头后期合成 | 每镜头一个配音，默认从镜头起点播放，可调音量 |
| 背景音乐 | 用于整片后期合成 | 统一到视频页选择，避免每个镜头重复设置 |

音频卡片显示播放按钮、名称、真实时长、用途、替换和移除；无波形分析能力时可只显示播放进度，不使用假的波形数据。全站同时只播放一段试听。

镜头配音短于片段时尾部留空；长于片段时阻止合成并提示调整镜头时长或换用音频，不默默截断旁白。背景音乐默认从零开始，长于成片时截取到片尾，短于成片时默认循环并在设置中明确显示。原声/配音音量与音乐音量分别可调；音量修改只影响合成，不触发重新生成镜头。

## 7. 镜头视频生成、版本与成片（RQ-110～RQ-113）

### 7.1 提交与批量

提交前确认保存成功，校验描述、模型可用性、画幅、时长、素材存在及用途数量。实际任务固定使用提交时输入；用户后续编辑产生新状态而不改变执行中的任务。

批量默认选择无成功结果且无执行中任务的镜头，也可手动勾选。提交摘要展示镜头数与不通过项；只有全部所选镜头通过校验才提交，也可明确选择“仅提交通过校验的 N 个”。部分创建失败时显示成功/失败名单，重试只针对失败项；已经创建的任务不重复创建。

状态统一“待生成 / 排队中 / 生成中 / 已完成 / 失败 / 已取消”。只有真实进度时显示百分比，否则用阶段文字。失败显示易读原因和重试；重试明确使用原任务输入，若要采用最新编辑则通过“按当前设置生成”。

### 7.2 视频版本

镜头成功结果按 v1、v2 顺序展示缩略图、时长、创建时间和对应输入摘要。首个匹配当前输入的成功结果可以默认选用；已有选用版本时新结果仅提示“新版本可用”，不自动替换。输入改变或乱序返回的旧任务结果标记“基于旧设置”。

旧视频仍可播放、下载或明确选用。“与当前设置不同”是内容新旧标记，不等同于任务失败。正文变化只标记分镜需复核，不使所有片段立即失效。用户复核旧版本后可以继续用于合成。

### 7.3 视频页

参考图：[05 视频与成片](images/05-video-assembly.png)。左侧播放器，右侧成片设置，底部镜头顺序条。顺序与分镜列表一致；如允许在此拖动，必须同步更新分镜顺序，不能维护两份不一致顺序。

每段显示镜头名、实际视频时长、选用版本和状态。合成前校验每个镜头均有可用已选视频、音频可用、输出画幅和清晰度可支持。缺少片段时禁用合成并提供“返回缺失镜头”入口。混合画幅采用等比适配加留边，不默认裁剪主体；清晰度选项仅展示合成能力支持项。

提交合成固定所选片段版本、顺序与音频设置；继续修改不改变执行中的合成。结果显示“最新成片”、实际时长、预览和下载。若输入随后变化，已有成片显示“有未合成的修改”，保留原文件。目标是简单拼接及混音；无成片能力时需明确呈现未开放状态并仍允许下载单镜头，不以空按钮冒充已实现功能。

## 8. 素材管理（RQ-114～RQ-117）

参考图：[04 素材管理](images/04-material-library.png)。

### 8.1 分类和布局

分类固定为“全部 / 场景 / 角色 / 道具 / 配音 / 音乐”。其中全部是汇总视图，不是可写入的分类。原“画面”改名“场景”，用“道具”替换独立“首尾帧”入口。

| 分类 | 媒体 | 典型内容 | 绑定时建议用途 |
| --- | --- | --- | --- |
| 场景 | 图片 | 街道、室内、环境氛围 | 场景参考 |
| 角色 | 图片 | 人物形象、服装、角色设定 | 角色参考 |
| 道具 | 图片 | 杯子、车辆、关键物品 | 道具参考 |
| 配音 | 音频 | 旁白、对白录音 | 镜头配音 |
| 音乐 | 音频 | 背景音乐 | 成片背景音乐 |

页面标题右侧“上传素材”，分类下方搜索名称或标签、媒体类型筛选、最近添加排序。卡片使用一致预览高度，图片等比适配，音频使用可试听卡片；显示名称、分类和更多菜单。点击卡片只打开详情，不设置全局“当前选用”。

右侧详情显示预览、可编辑名称、格式/尺寸或时长、分类、标签、使用位置和下载。使用位置按项目/草稿/镜头列出，可跳转；成片音乐和保留版本也应说明引用来源。

### 8.2 上传和编辑

支持多文件选择及拖入上传区；全部视图上传时选择分类，具体分类下预选当前分类。图片只允许场景/角色/道具，音频只允许配音/音乐；类型不符在提交前提示并可调整分类。格式和大小上限在选择器中展示实际支持值。

逐文件显示上传中、成功、失败和重试，部分失败不撤销成功文件。不覆盖同名素材，名称可重复但选择时显示预览与媒体信息。上传成功停留在当前上下文；从镜头内上传会预选成功素材，用户确认后才绑定镜头。

重命名、标签或分类调整不改变文件和引用身份；替换文件采用新增素材，再由用户选择是否替换某个镜头的绑定。图片加载失败可重试，仍展示名称和用途。

### 8.3 删除与历史兼容

删除未引用素材前确认名称与数量。正在被草稿、执行中任务、保留镜头版本或成片引用的素材禁用永久删除，并提供使用位置；删除操作时再次核验引用，不能仅凭页面打开时的状态决定。取消绑定只删除关系，不删除素材文件。

旧分类的兼容策略：画面 → 场景；角色、配音、音乐保持；首尾帧 → 场景并附“原首尾帧”标记。保留素材身份、文件、历史任务输入；若旧数据已有明确首帧/尾帧用途则保持，若仅有全局选中状态则不推断绑定到所有镜头，等待用户在具体镜头选择。

## 9. 空态、异常与反馈（RQ-118、RQ-119）

| 场景 | 展示与恢复 |
| --- | --- |
| 无正文 | 可编辑空白区、导入、故事联想；生成分镜禁用并说明 |
| 无分镜 | “先从正文生成分镜，也可以手动新增”；保留返回正文入口 |
| 素材库为空 | 上传入口与支持类型；不展示假素材 |
| 搜索无结果 | 保留搜索词，提供清除筛选 |
| 模型未配置/不可用 | 显示所需能力和前往配置入口，编辑内容保留 |
| 保存失败 | 持续状态提示与重试，生成前阻止继续 |
| 任务失败 | 原因、任务详情与重试，已有成功版本保留 |
| 绑定素材缺失 | 卡片显示缺失标记，更换/移除；阻止依赖它的新任务 |
| 结果晚到或重复到达 | 只归入原项目/草稿/镜头，去重展示，不覆盖新编辑 |
| 页面重开 | 恢复保存内容、候选结果和任务状态，不自动重复提交 |

浮动提示用于成功反馈；需要用户处理的问题放在对应字段或常驻提示区。全局错误不可只闪现几秒。全屏面板按 Esc 关闭并恢复焦点；选择器有未确认选择时 Esc 等同取消；正在输入时不触发全局快捷删除。

## 10. 验收场景与规格映射

| 场景 | 验收结果 | 需求 |
| --- | --- | --- |
| 粘贴完整故事后生成分镜 | 无需故事联想，正文保持，候选可应用 | RQ-102、105 |
| 联想生成中编辑正文后关闭抽屉 | 任务继续；重开有预览，正文未覆盖 | RQ-103、104 |
| 在已有分镜上重新生成 | 替换有明确操作，可恢复旧镜头与绑定结果 | RQ-105 |
| 镜头 A/B 分别绑定不同素材并排序 | 素材跟随镜头身份，互不串用 | RQ-106～108 |
| 给单首帧模型绑定多图/音频参考 | 明确指出不支持项，禁止静默提交 | RQ-109、110 |
| 多个镜头批量提交时部分创建失败 | 成功项保留，重试仅失败项 | RQ-110、111 |
| 生成后修改镜头并收到旧任务结果 | 新旧版本可辨识，已选结果不被抢占 | RQ-111、112 |
| 缺一个片段或配音超过镜头时长 | 合成不可提交，定位需处理的镜头 | RQ-109、113 |
| 成片提交后改变顺序 | 当前任务使用原顺序，新编辑可继续保存 | RQ-113 |
| 素材分类调整与旧数据载入 | 首尾帧入口消失，旧文件与引用完整保留 | RQ-114、117 |
| 从素材库详情删除被引用素材 | 显示使用位置，删除受阻；解除绑定不删文件 | RQ-116 |
| 上传部分失败、保存失败、重开页面 | 有独立重试，不丢失已成功操作与编辑 | RQ-115、118 |
| 键盘/窄屏操作抽屉 | 可进入退出、焦点合理、主要内容可读 | RQ-119 |

## 11. 与现有实现和旧计划的关系

以下是仓库检查发现的差异，不能把概念图当作已实现能力：

| 当前事实/旧计划 | 本次设计要求 | 后续计划需同步 |
| --- | --- | --- |
| 旧 plan.md 以生成 summary/body/scenes 为一次动作 | 正文生成与分镜生成是独立的用户动作 | 区分生成目标与应用范围，正文流程不能强制要求 scenes |
| 当前故事结果会写回正文，旧计划无冲突时自动应用 | 始终先预览再显式应用 | 候选保存、明确应用、恢复与并发编辑保护 |
| 现有 Scene 主要为描述、旁白和时长 | 每镜头绑定素材、拥有任务与版本 | 补齐归属、绑定用途和历史输入快照 |
| 现有 TaskInput 只有 prompt、aspect_ratio、source_image_url | 多图用途、参考音频和镜头归属按能力支持 | 调研提供者能力，更新输入契约与校验；不能仅修改界面 |
| 素材当前按 visual/character/frame/voice/music 分类，全局选用 | 场景/角色/道具/配音/音乐，按镜头绑定 | 兼容历史分类，消除全局选中影响镜头 |
| 现有素材管理偏向上传/预览/删除 | 名称、标签、查询、详情、引用保护 | 补足数据和交互能力 |
| 旧计划不含成片合成 | 简单拼接、配音/背景音乐和导出 | 合成能力及任务、输入版本、媒体有效性校验需独立设计 |

旧计划中可复用的方向包括结构化输出校验、服务端稳定镜头身份、任务归属、重复回调幂等和历史数据兼容。但“整体自动替换故事文档”、固定“故事必含分镜”、image/video 不变等边界已不适用于完整新体验。旧 RQ-001～RQ-008 不与本规格 RQ-101～RQ-120 自动对应。

本轮保留旧技术方案作为参考；后续 /plan 需覆盖上述差异后再拆分任务，不应直接按旧 plan.md 编码。
