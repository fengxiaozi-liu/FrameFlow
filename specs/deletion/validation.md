# 草稿与厂商删除验证

日期：2026-10-09。Phase 1 全部完成。

## 交付

- 创作工作台提供独立的“删除草稿”按钮；多个草稿通过“其他草稿”展开后可逐个删除。
- 删除指定草稿的正文、分镜和版本记录；保留其他草稿、项目共享素材及已完成任务与文件。
- 模型管理工具栏提供“删除厂商”，原子删除连接与全部模型配置，并清理保存的密钥。
- 删除前确认范围；提交期间防重复点击；失败显示原因并可重试，成功刷新列表与空状态。
- 关联排队/运行中任务会阻止删除；草稿版本校验、删除标记和事务检查防止陈旧保存及迟到任务恢复已删除数据。
- OpenAPI 与前端接口类型已同步。

## 验证

- go test ./...：完整后端测试通过。新增仓储与 HTTP 测试覆盖版本冲突、删除隔离、关联任务保护、素材引用更新、历史保留、模型级联、密钥清理及迟到写入。
- Playwright 完整回归：43 项全部通过（35.4 秒）。覆盖取消、失败重试、多草稿指定删除、厂商级联、其他配置保留、重载后持久化及空状态。
- 390px 页面无横向溢出，草稿页 axe WCAG 2A/2AA 检查通过；已检查桌面及手机截图。
- npm run build（含 vue-tsc）、npm run lint、git diff --check 通过。
- 实际 EXE 使用隔离数据库、上传目录与密钥目录启动：健康检查、最新前端资源、真实草稿 DELETE 204、厂商 DELETE 204、关联模型清空、正常退出均通过。
- 未调用付费模型，未删除用户现有数据。测试截图及 EXE 结果位于 artifacts。
