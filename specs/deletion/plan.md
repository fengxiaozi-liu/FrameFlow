# 草稿与厂商删除

工作台在草稿卡片提供独立删除操作，同一项目的其他草稿可展开管理。删除前明确名称及范围：移除该草稿正文、分镜及草稿内版本记录；保留其他草稿、项目素材和已完成任务文件。不执行文件清理。使用 expected_version 防止误删其他窗口的新修改。服务端原子检查活动任务和版本，删除后更新素材引用索引，记录删除标识以防旧页面保存或迟到任务重新创建草稿。

模型管理工具栏提供删除厂商入口，确认会同时删除该连接的模型配置与保存的密钥。已完成任务和文件保留；排队或运行中的关联任务阻止删除。模型配置与连接在同一数据库事务中删除，并记录已删模型标识，阻止迟到任务入队；重试失败任务时由已有模型可用性检查反馈。

操作提供取消、提交中禁用、错误反馈和成功后的列表更新。相关测试用隔离数据库与测试项目，验证跨草稿隔离、活动任务阻止、版本冲突、陈旧保存、级联配置删除、历史任务保留、取消及失败重试。更新接口文档并交付测试包。
