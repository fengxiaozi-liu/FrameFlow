# 参考素材直接生成视频（2026-10-08）

> 同日后续调整：新增即进入详情、顶部名称、补充迁移与人物音色，见 [分镜入口与人物音色说明](shot-entry-and-voice.md)。

本次在分镜工作区基础上迭代；新流程以本文为准，旧流程兼容规则见 `shot-task-workspace.md`。

## 页面与操作

- 分镜列表进入配置详情；一次点击「生成视频」创建一个 GenerationRun，成功或幂等恢复后立即进入对应任务详情。
- 配置卡顺序为引用素材、场景描述、视频设置、生成视频。人物动作、景别、运镜写在描述里。
- 场景与人物使用同一右侧抽屉，填写名称、参考图片、参考描述。保存并引用后关闭；失败保留内容并可重试。编辑生成新素材版本，当前分镜采用该版本。
- 新任务只包含一个视频 Task；重试沿用原 Run 和冻结输入。再次明确生成会创建新 Run。视频预览、下载、选用、取消和重试在任务详情操作。

## 模型与参数

在模型管理中，为百炼连接添加 `wan2.7-r2v`（或 `wan2.7-r2v-2026-06-12`），选择视频能力并配置有效密钥，再在分镜中选择它。

新流程要求总计 1–5 张参考图片，2–15 秒，720P 或 1080P，比例 16:9、9:16 或 1:1。所有选用图片按冻结顺序传给参考生视频模型；超限会提示精简。现有上传大小限制仍为每张 10 MB。

旧 i2v 模型不具备这里所需的多图引用能力，需在当前分镜显式换选 r2v。程序不自动修改已有模型连接或密钥。

## 数据与历史兼容

- 新快照路径为 `reference_video`；`generation_settings.image_model_id` 改为可选。
- 无破坏性数据库表迁移；既有 Run、Task、素材版本和文件保留。
- 历史 `reference_image_then_video` / `first_frame_video` 继续显示原生图、配音、视频流程。旧视频选择和重试沿用原规则。
- 新流程的旁白、台词文字写入视频提示，不创建独立配音 Task。成片时保留所选参考视频的原片音轨，跳过旧台词配音及旧 voiceover 绑定；历史视频仍校验原配音。
- 参考素材、描述及模型参数在提交时冻结；修改配置不回写已创建任务。

## 验证边界

厂商协议通过本地 HTTP 模拟测试；未进行真实付费生视频。正式使用仍需有效百炼账号、模型权限及符合厂商要求的图片。模型是否生成预期对白、音色、画面质量，需要实际生成验证。本次回归及打包记录见 `specs/reference-video-workflow/validation.md`。
