# 场景、人物与音色绑定升级

## 升级与回退

停止服务后备份整个 data 目录（SQLite 数据库、uploads、vault），再启动新版本。迁移版本 2 重建素材引用索引，重复启动不会重复实体。历史单图绑定原样保留；无法推断人物身份的素材留在素材库，由用户手动归组。

新字段与历史记录保存在项目 JSON 聚合中。旧二进制不理解这些字段，回退必须停止服务并恢复升级前的完整备份，不能让旧版本直接写新版数据库。已有实体采用不可变版本；归档不删除历史引用。引用中的素材不可删除。

此版本未引入可运行时切换的特性开关；新旧数据路径同时兼容，回退用完整备份。测试通过 FRAMEFLOW_DATABASE_PATH、FRAMEFLOW_UPLOAD_DIR、FRAMEFLOW_VAULT_DIR 隔离，不能复用生产数据目录。

## 使用流程

在「分镜」中添加场景或人物；每组可保存描述、多张有序参考图及视角标签。项目设定保存为新版本，仅当前镜头采用该版本，其他镜头保留原设定；「本镜头补充」只影响当前镜头。复用项目档案时按 ID 区分同名人物。

输入 @ 插入实际绑定；人物默认音色在设定中配置，每句台词可以单独覆盖，旁白必须显式选择音色。配音按台词顺序与停顿合成，超过镜头真实时长会阻止合成，需要缩短台词或重新生成更长视频。逐句配音会静音原片，避免人声重叠；当前不保证口型同步。

「开始完整制作流程」生成分镜图和配音，等待人工选用后继续生成视频，再选择视频版本并在「视频」页合成成片。刷新或服务重启保留流程。进程中断且供应商是否处理未知时停止并提示手动确认重试，避免自动重复计费。

自动保存失败时保留本地暂存；版本冲突展示服务器内容，用户明确选择保留本地镜头或使用服务器内容。任务通知不替换未保存的绑定编辑。

## 能力与数据大小

当前已实测 qwen-image-2.0-pro 最多选用 3 张图、单图 10 MB；档案可以保存更多图，但生成前必须主动取消多余选用图。qwen3-tts-flash 使用官方 Cherry/Ethan 音色；wan2.7-i2v 采用首帧路径。未确认模型不声称支持多图。

上传内容保存在独立文件，JSON 仅存 ID、版本、摘要和标签；不存 base64 图片或密钥。实体历史、快照和结果数量增长会线性增加项目 JSON；不要把生成结果或原始图像写入描述字段。生成输入哈希排除临时 URL 和时间，以内容摘要、描述、顺序和生成参数辨别依赖。

亮色页面与暗色编辑区域共享蓝绿色主题；小屏幕可折叠分组。素材移除只解除当前绑定，永久删除仍受引用保护。
