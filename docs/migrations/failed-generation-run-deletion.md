# 失败生成记录删除（2026-10-13）

生成记录列表、制作任务详情和任务中心增加“删除任务”。仅失败的制作任务可删除；弹窗确认后同时删除 GenerationRun 和所属终态子任务。失败流程中已完成的素材、视频版本、选用记录及本地媒体文件保留。取消确认或接口失败会保留记录并允许重试。

删除用例位于 application，HTTP handler 位于 interfaces/http，删除条件由 Project 聚合检查，SQLite 适配器在同一事务中修改项目、任务及素材引用。任务中心删除 Run 的子任务会走同一用例，不单独删除步骤。存在 queued/running 子任务或 Run 已不再失败时返回 409；项目、草稿、分镜归属不匹配或记录已删除时返回 404。

`DELETE /api/projects/{id}/drafts/{draftId}/scenes/{sceneId}/generation-runs/{runId}` 成功返回 204。既有 `DELETE /api/tasks/{id}` 对 Run 子任务使用上述规则，独立任务仍可删除终态记录，活动任务禁止删除。契约维护于 OpenAPI，前端类型重新生成。

删除增加草稿版本并使用既有 deleted_resources 表记录 Run、已有步骤及尚未创建的计划步骤。迟到的任务保存、重复提交和旧项目整体保存不能恢复已删除记录；结果回写也检查 Run 是否仍然存在。视频版本增加可选 `generation_path`，新结果保存来源，历史视频在删除时从任务快照补齐；合成继续保留直接生成视频的原片对白，不因任务消失要求额外 TTS。前端忽略已删除记录的旧轮询响应，详情删除后返回分镜并恢复到生成记录标题的焦点。旧 JSON 缺少该字段时仍按任务快照判断，无新增数据库表或破坏性数据迁移。

升级前按发布指南停止程序并备份 data；验证使用隔离数据库，不删除真实任务。降级旧版本不会识别新的 Run/Task 删除保护，需要停止程序后恢复升级前备份，不能把旧版本的迟到写入合并回新数据。

验证覆盖领域删除规则、SQLite 事务与共享素材引用、跨分镜拒绝、活动步骤拒绝、尚未创建步骤、迟到保存和结果回写，以及取消确认、失败重试、刷新持久化、手机布局、键盘操作和任务中心同步。真实付费生成未执行。

本次用户任务的冻结配置请求 `https://ai-token-admin.xtt.xyz/v1/generate`，服务返回 HTTP 404。用户后续提供的服务商文档确认应使用视频任务入口并异步查询，配置与文档不符。完整路径、字段映射、两份文档矛盾和参考图交付限制见 [bonkeAI 配置分析](../bonke-video-configuration.md)。修改配置后需要重新生成；“按原输入重试”仍使用该任务提交时的冻结配置。
