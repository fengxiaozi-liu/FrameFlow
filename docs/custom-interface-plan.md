# 自定义接口改造

## 目标与设计

接口协议分为内置协议与自定义 JSON 接口。内置协议展示固定路径；自定义接口独立定义路径、请求模板和结果提取，不能再复用 DashScope 编码器假装支持其他格式。

采用现有 Registry + Adapter：增加 `custom.json.v1` 适配器。领域层持有和校验版本化配置值对象，应用层保持统一生成端口，基础设施负责 JSON 替换、HTTP 和结果解析。配置随现有模型修订和任务快照持久化，不新建平行存储。

首版边界：HTTPS JSON POST；认证支持连接密钥的 Bearer、自定义请求头或无认证；文本、图片和语音同步返回；视频支持同步返回和异步 GET 查询。媒体结果为 HTTP(S) URL。暂不支持 multipart、流式响应、签名脚本、任意代码或异步图片/语音任务。模板变量必须占据整个 JSON 字符串值，保留数字和数组类型；结果用 JSON Pointer 定位，避免猜测厂商字段。

历史内置协议路径覆盖保持执行语义，界面只读标注“历史路径配置”，允许显式恢复默认路径。新的自定义接入从独立协议选项开始，切换协议不自动猜测迁移格式。
