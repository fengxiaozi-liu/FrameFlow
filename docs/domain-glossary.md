# Domain glossary

- Project: a video creation container.
- Draft: an editable version of a project's story and storyboard.
- Story document: summary, continuous text, characters, and ordered scenes.
- Scene: one timed storyboard unit with visual prompt and narration.
- Material: visual style, frame, character image, voice, or music asset.
- Provider: configured AI endpoint with one capability: story, image, or video.
- Generation task: durable asynchronous work with ordered progress events.
- Task event: immutable status, stage, and progress snapshot used for replay.
