# 模型协议与参数配置

适用版本：2026-10-12 本次工作区改造。

## 使用方法

1. 在模型管理中添加连接，只填写 HTTPS 基础 URL（例如 `https://example.com:8443`），不包含 `/v1` 或 `/chat/completions`。同步或手动添加模型。同步仅返回模型 ID 时，可以直接进入「协议与参数」配置能力。
2. 点击该模型的「协议与参数」，选择文本、图片、视频或语音能力。协议列表随能力切换；未选择能力时不会默认展示文本协议。内置协议直接展示固定请求路径；自定义接口填写生成路径、执行方式，粘贴普通请求与响应 JSON 示例，并选择业务字段映射。认证继承连接设置。
3. 视频可同时勾选首尾帧与智能参考（多图），并配置比例、时长、清晰度、图片数量与大小；图片配置各比例对应尺寸；语音配置音色 ID、语言、文字上限。时长默认填写最短与最长秒数（1–3600 的整数），包含两端，按 1 秒递增；起止相同表示固定时长。只支持固定档位的模型可选择“指定时长”，已有离散配置会保留为该模式。范围提交为允许秒数集合，分镜选择与后端校验使用同一集合。清晰度和音色语言使用可增删标签，输入一个值后按回车或点添加。清晰度也可点选常用值，默认不勾选；实际支持范围以模型文档为准。时长自动排序，重复值不会重复添加。
4. 保存会在一次版本校验和事务中提交能力声明及协议参数；取消或保存失败不会部分修改模型。原本未启用的模型仍需在列表勾选「启用」。随后返回分镜详情选择模型，时长、清晰度和比例随模型配置变化。首尾帧模式从当前分镜引用中明确选择首帧与可选尾帧；智能参考使用全部引用图片。切换保留选择，提交时只使用当前模式的输入。详情见 [视频模式设计](video-input-modes.md)。

「配置就绪」只表示本地配置可执行，不等于厂商连接成功或真实生成验证成功。模型能力勾选和启用不会自动推断接口格式、时长或清晰度。

## 已实现的协议

| ID | 请求与响应格式 | 默认路径 |
| --- | --- | --- |
| openai.chat.v1 | messages → choices.message.content，同步文本 | /compatible-mode/v1/chat/completions |
| dashscope.image.v1 | 多模态 messages/content、parameters.size → output.choices 图片 | /api/v1/services/aigc/multimodal-generation/generation |
| dashscope.media-video.v1 | input.media、parameters → task_id；轮询 task_status/video_url | /api/v1/services/aigc/video-generation/video-synthesis；轮询 /api/v1/tasks/{id} |
| dashscope.speech.v1 | text/voice/language_type → output.audio.url | /api/v1/services/aigc/multimodal-generation/generation |
| custom.json.v1 | 按配置替换 JSON 变量、提取响应字段；视频可异步查询 | 用户独立配置，无默认路径 |

内置协议使用连接的 HTTPS 域名及 Bearer 凭据。内置视频协议同时展示提交任务（POST）与查询任务（GET）路径。旧版的路径覆盖继续按原协议执行，界面以“历史路径配置”只读展示，允许主动恢复协议默认路径。新接入请使用独立的自定义接口配置；改变路径不会自动改变数据格式。

百炼目录接口固定为 `/api/v1/models`，按页读取模型和 TG/IG/VG/TTS 能力。只有自定义厂商在新增连接或连接设置中填写同步接口，默认 `/v1/models`。界面中的列表、模型 ID 和名称使用 Key 填写，例如 `data`、`id`、`name`；嵌套结构使用点号路径，例如 `result.models`。保存时系统会转换为内部 JSON Pointer（如 `/data`），因此用户不需要手写斜杠。支持 GET/POST 和分页。自定义同步只导入 ID/名称，能力在模型「协议与参数」中配置。未注册目录适配器的厂商会提示手动添加；同步失败不自动改用另一接口。

同步保留人工修改、禁用和清空的能力选择；连接测试只验证目录查询，不代表生成能力验证。生成地址统一为“基础 URL + 协议路径”，内置协议和自定义接口均展示最终地址，异步视频同时展示轮询地址。厂商目录不决定模型生成协议。新契约不迁移旧完整接口地址。

## 自定义接口（custom.json.v1）

自定义格式由独立适配器处理，不进入内置 DashScope 编码器。支持四类能力的同步 JSON、SSE/NDJSON 响应，以及视频异步提交与 GET 查询。流式文本片段合并为最终文本，媒体使用最后一个结果 URL；当前不把每个流片段推送到前端。设置完成标记时缺标记会报错。范围不含 multipart、脚本、动态签名、任意对象数组转换、Base64 媒体结果、驱动音频上传或异步图片/语音任务；这些需要明确扩展适配器。

1. 选择“自定义接口（JSON）”，填写从 `/` 开始的完整生成路径。与连接的基础 URL 组合，不自动追加 `/v1`。路径不含查询参数或密钥。
2. 在连接设置选择 Bearer Token、自定义认证请求头或无需认证。新模型协议继承连接认证；旧自定义模板仍保留原编辑器和认证设置。密钥只进入凭据设施，不写入 JSON 示例、请求头固定值或前缀。
3. 展开“粘贴 / 修改 JSON”，粘贴普通请求 JSON 对象示例，系统自动生成字段表：字段 Key / 类型、示例值 / 固定值、生成时取值。逐行选择模型 ID、提示词、图片、时长等参数；新增字段默认“不绑定 · 保留示例值”，不推测字段含义。字符串、数字、布尔固定值可直接在表格修改，数组和结构在 JSON 编辑器修改。已绑定字段在生成时使用实际参数。示例解析上限 128 KB、深度 32、4096 节点，编译后的请求上限 64 KB。不上传示例文件、不要求填写占位符。
4. 请求、响应、受理响应和查询响应统一使用树形字段设置。对象和数组显示父级行，可逐级展开、折叠；例如 `list → a → c`，在 a 内直接设置 c，不把嵌套字段压成点号名称。数组项显示为 `[0]`、`[1]`，同名字段分别位于各自父级内；空对象和空数组也会显示。响应选择“提取为”的业务参数，“不绑定 · 忽略此字段”表示不读取该字段。折叠只改变显示，不删除值或绑定。存储和运行仍使用完整 JSON Pointer，原映射直接回显。文本结果、媒体 URL、任务 ID 和状态字段须返回非空字符串。媒体结果只支持 HTTP(S) URL，不接受本地路径或内联 Base64。旧模板编辑器保留原 JSON Pointer 输入方式。
5. 异步视频还需要任务 ID 字段、含一个 `{task_id}` 的 GET 查询路径、状态字段，以及等待/成功/失败三组状态标签。状态区分大小写且不允许跨组重复。成功时从查询响应提取结果 URL；未知状态、缺字段、远端失败均明确报错。

每个字段都可以解除绑定；协议所需的模型 ID、正文参数和结果等仍须有对应字段，保存时由后端权威校验。界面会禁用类型不符、参数已被其他字段使用、父子字段同时绑定等选项。模型/提示词等为字符串，images/messages 为数组，duration 为数字；整个数组绑定后，其子字段随该参数整体传入。

视频默认请求示例包含 `images: []`，对应“智能参考图片（多图）”（内部变量 `images`）；`first_frame` 对应单独的首帧图片。已有自定义示例如果缺少图片数组，请按服务商文档补充实际字段，例如 `input.references: []`，在该数组行选择“智能参考图片（多图）”，不要绑定某个数组元素。运行时传入本次智能参考模式下的图片地址数组；模型能力中还需勾选“智能参考（多图）”并配置最大参考图数量。更新不会自动重写用户已经保存的请求 JSON。

修改 JSON 时保留原绑定；字段缺失会列出待处理绑定，可点击“解除绑定”后重新选择。字段类型改变会显示类型冲突，不会静默删除绑定。无效 JSON 保留输入和原绑定，修正后继续配置。JSON 编辑区可折叠，避免示例与字段列表同时占用大量侧栏空间。

“协议与参数”侧栏默认宽 720 像素，可拖动左侧手柄调整宽度。手柄获得焦点后，左右方向键调宽，Shift 加方向键加大步长，Home/End 调到最窄/最宽；宽度受当前窗口限制。640 像素及以下采用全屏单列，隐藏调宽手柄。内容区域独立滚动，标题与底部保存操作可保持可见；关闭恢复打开面板前的焦点。

| 能力 | 可映射变量 |
| --- | --- |
| 共用 | `model`：远端模型 ID，必须映射 |
| 文本 | `prompt`、`system_prompt`、`messages`（含系统和用户消息的数组） |
| 图片 | `prompt`、`images`（图片地址数组）、`ratio`、`size`（如 `1024*1024`） |
| 视频 | `prompt`、`images`、`first_frame`、`last_frame`、`duration`（数字）、`resolution`、`ratio` |
| 语音 | `text`、`voice`、`language`、`instructions` |

图片输入可能为已转码的 Data URI，服务端必须支持该输入形式；这里只映射地址，不代替厂商上传接口。模板中的 `model` 和正文变量必须存在；配置参考图、首帧或尾帧能力时，必须映射对应变量。时长、比例等参数也需按服务商约定映射到对应字段。

例如某同步文本服务接受下面的格式，可粘贴普通请求示例（仅示意，不代表 Seedance 的实际接口）：

```json
{
  "engine": "example-model",
  "input": { "messages": [{ "role": "user", "content": "示例问题" }] },
  "stream": false
}
```

映射模型 ID → `/engine`、消息列表 → `/input/messages`。粘贴响应示例 `{"payload":{"answer":"示例文本"}}`，结果映射 → `/payload/answer`。OpenAI 风格可映射 `/choices/0/message/content`。用于生成分镜时，提取出的文本仍须满足应用的分镜结构。结果、远端任务 ID 和状态必须映射字符串；运行响应新增未映射字段不会使配置失效。

请求遵循调用方取消和超时，HTTP 响应限制 4 MB，不跟随重定向，不自动重试提交请求，不在错误中输出密钥或原始响应正文。视频复用原有远端任务 ID 持久化、冻结配置、轮询和重启恢复机制；取消本地任务不代表远端服务已经停止计费。


画布当前支持 16:9、9:16、1:1；本地图片传输上限 20 MB，视频模型配置必须收窄到实际限制。驱动音频还依赖现有对象存储配置；音频指令控制当前协议不支持。

## 架构扩展

- 领域：`provider.Model` 持有按操作划分的 `OperationBinding`；`Resolve` 返回能力状态及原因，`Configure` 校验并生成新修订。
- 用例：`application.ModelConfiguration` 协调模型配置；新 handler 位于 `interfaces/http`。
- 协议：Registry 按显式协议版本查找适配器，文本/图片/视频/语音使用窄操作接口，不按厂商名或模型名前缀分派。
- 同协议新模型：只新增配置，RemoteID 原样提交。新协议：增加协议描述与校验、窄接口适配器、组合注册及契约测试。初版支持编译期注册，不提供动态脚本插件。
- 既有 ModelClient 作为旧执行器兼容接口保留；旧 handler 的完全迁移不属于本次改造。

## 数据兼容与任务

SQLite JSON 增加 `revision`、`operations`。旧模型通过幂等的 `legacy-preset.v1` 读时兼容转换，下次保存持久化；未知 ID 保留但提示待配置。已显式保存的配置（含空配置）不会被预设覆盖。

任务及生成运行保存创建时模型、协议、参数规格快照和素材快照，不包含密钥。配置更新使用预期修订；过期配置保存返回冲突。执行、重试使用冻结的模型配置；没有快照的历史任务在首次恢复执行前解析并保存兼容快照，无法恢复提交时的未知配置历史。

取消、幂等和远端任务 ID 沿用原有流程。新任务同时冻结连接地址与认证策略，凭据轮换仍按连接 ID 读取。自定义 POST 网络失败或异步受理数据不可解析时保存“远端受理状态未知”标记，禁止普通重试，先在服务商确认；尚不提供通用未知提交查询或自动补发。旧任务缺少连接快照时仍使用既有连接读取路径。

升级前按 release.md 备份数据库、媒体和 vault。没有破坏性表结构迁移；旧程序不识别新协议配置及快照，回滚应恢复升级前备份，不用旧程序继续新配置下的待处理任务。

## 取消模型选择

模型列表的类型筛选支持再次点击当前类型回到“全部”。能力、启用、默认选项均可取消；取消全部能力会同时关闭启用和默认状态，保留协议与参数以便后续重新配置。

手动能力选择（包括空列表）保存 `capabilities_configured` 标记，再次同步不会恢复被主动取消的能力。未经过手动配置的未知模型仍可接受新的发现结果。侧栏保存能力与协议也使用相同规则。保存失败时复选框恢复原值并显示错误。

## 图片生成：先配置模式，再使用

在模型的“协议与参数 → 图片生成”勾选文生图、图生图，可同时启用。图生图需填写最少 / 最多参考图、单图大小上限和支持的画幅 / 输出尺寸；保存并启用模型后，人物或场景侧栏的“图片生成 → 图生图”才可使用。未声明或未配置完整的模型会显示不可选原因。

百炼 `qwen-image-2.0-pro` 可参考内置示例参数：1–3 张图片、单张 10MB，输出 `1280*720`、`720*1280` 或 `1024*1024`；请核对服务商当前文档。自定义接口需在 JSON 示例字段中绑定 `images`（参考图片数组），并绑定 prompt、model 等实际需要的参数。本地图片按顺序转换为 data URI；只接收公网 URL、multipart 或特殊对象结构的接口不能仅靠这组配置运行。

当前图生图输入支持 PNG / JPEG，返回一个结果。输入原图不会覆盖，结果采用和上传素材库分别确认。完整分层、兼容、配置说明及实际界面见 [实施记录](../specs/image-generation-modes/plan.md)。
