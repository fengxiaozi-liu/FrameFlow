# 厂商基础地址与模型目录改造

日期：2026-10-10。用户确认项目尚未上线，本次直接采用新契约，不迁移旧连接、不回退旧完整接口地址。

## 设计

- 连接持有 HTTPS 基础地址（域名和可选端口）、凭据引用、厂商身份。
- 领域层统一组合基础地址与协议路径；内置协议、自定义 JSON、轮询遵守相同规则。
- 模型发现采用显式 Registry + Adapter：按所选厂商自动确定目录；百炼原生目录和其他兼容服务目录分别注册。未注册厂商提示手动添加，目录与生成协议独立。
- 百炼原生目录处理分页和能力元数据；缺失能力保留待配置，不按模型名称推断执行能力。同步保留人工配置。
- UI 展示生成、轮询地址；厂商表单不展示同步方式及目录技术说明。基础地址不接受完整接口路径；用户按明确提示填写。
- 本次不重写历史任务或其余历史迁移机制，也不修改用户已有数据。
